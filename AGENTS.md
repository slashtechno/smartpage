# Smartpage

## Purpose
This project exists for the user to LEARN — not to have code written for them.
- Provide docs, official resources, and conceptual pointers — do NOT scaffold or generate code
- Do not create files, boilerplate, or starter code unprompted
- Any file the agent does generate must have a comment at the top: "Generated by agent — YYYY-MM-DD"

## Stack
- **Mobile**: Expo (React Native) — camera + share extension
- **API**: Hono on Bun
- **Database**: Postgres via Bun's built-in SQL client (`import { sql } from "bun"`)
- **AI**: Claude vision API (image → structured event data)
- **Calendar**: Google Calendar API (or Apple EventKit for iOS-only)

## What it does
1. User takes a photo (or shares one from another app)
2. Expo sends the image to the Hono API
3. Hono calls Claude vision to extract event details (date, time, title, location)
4. Hono writes the event to Postgres using raw SQL
5. Hono optionally creates a Google Calendar event

## Learning goals
- Raw SQL with Postgres (no ORM): SELECT, INSERT, migrations, schema design
- Mobile dev with Expo: camera, share extensions, fetch/multipart uploads
- Hono: routing, middleware, file uploads, JSON responses
- Monorepo (expo frontend + hono backend) with Bun Workspaces with RPC for type safety
